# PRD: Web 商城暗色模式（跟随系统）

## 问题与背景

商城视觉系统只定义了浅色暖纸令牌。操作系统处于暗色时，访客仍看到
高亮暖白页面。`docs/adr/web-visual-system.md` 初版否决过深色主题
（当时只选定浅色方向）；现需在不改浅色外观、不加开关的前提下，
补一套跟随系统的暗色对应面。

## 目标用户

- 与 `docs/prd/web-storefront.md` 相同：被链接带到首页、`/shop` 或
  pack 详情页的访客，其设备使用系统暗色或浅色外观。

## 用户故事

- 作为把系统设为暗色的访客，我打开任意商城页面就看到暖调暗色界面，
  不需要寻找主题开关。
- 作为把系统设为浅色的访客，我看到的仍是原来的暖纸白底，观感不变。

## 目标

- 全站外观跟随操作系统的 `prefers-color-scheme`。
- 暗色是现有 Cursor 暖灰焦橙系统的对应面，不是另一套风格。
- 浅色令牌与浅色观感保持不变。

## 非目标

- 不提供手动切换、不记住个人偏好、不提供「跟随系统 / 浅色 / 暗色」三态。
- 不改 pack 封面策略，不改文案、路由或数据契约。
- 不引入主题库或客户端主题状态。

## 范围与用户流

访客打开 `/`、`/shop` 或 `/[slug]`。浏览器按系统外观选用浅色或暗色令牌。
界面上没有任何主题控件。未声明系统偏好时保持浅色。

## 用户可见状态

- 系统浅色或无偏好：现有暖纸白底、墨色主色、焦橙强调。
- 系统暗色：暖黑底、浅色墨、同一焦橙强调；终端/代码块仍是最深的暖黑井。
- 系统外观中途变化：页面令牌随之切换，无需刷新。

## 验收标准

- 系统暗色时，首页、`/shop`、详情页均为可读的暖调暗色，对比度足够。
- 系统浅色时，观感与本功能之前一致。
- 全站没有任何主题开关或「浅色 / 暗色」文案。
- 终端卡片与安装命令条在两种外观下都保持深色井，不随页面反相成浅色。
- 公告条与首页收尾 CTA 在暗色下仍是暖墨带（浅色字），不反相成浅色块。
- 业务组件不新增硬编码颜色；换肤只通过语义令牌。
- `npm run build` 通过。

## 已解决的产品决策

- 只跟随系统，不支持手动切换（2026-08-21 质问确认）。
- 暗色沿用 Cursor 暖调对应面，不另选风格。
