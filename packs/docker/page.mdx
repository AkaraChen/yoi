Docker 是容器的事实标准：开源、免费，跑在每一朵云和每一台 Linux 机器上。当年跑云计算的底座，现在也是 agent 脚下的运行时。

## 它是什么

Docker 把应用连同依赖一起打包成「容器」——一个轻量、隔离、随处可运行的单元。装了 Docker，你的机器就能跑起整个开源世界的镜像：数据库、面板、agent、自托管服务，一条命令一个。

它由 Docker 公司与社区共同维护，上游是开源的 Moby 项目，Apache 2.0 许可。Mac 和 Windows 上的桌面版叫 Docker Desktop；在 Linux 服务器上，装的就是 Docker 本体。

## 数字

- Docker Hub 每月镜像拉取超过 **200 亿**次
- 每天超过 **2000 万**开发者用 Docker 构建
- 财富 100 强里 **91%** 跑在 Docker 上

## 为什么是它

标准意味着省心：镜像、教程、CI 都在这条轨道上，不需要新生态，不需要迁移。本地起步，随处运行——在笔记本上跑起来的容器，原样就能进入任何一朵云。
