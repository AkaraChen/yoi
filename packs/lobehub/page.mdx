LobeHub 是你的首席 Agent 运营官：把专属 Agent 组织成 7×24 不打烊的队伍，自动招募适配的 AI 队友、调度任务排班、汇总工作报告——你始终掌控全局，无需时刻在线盯守。

## Agent 即工作单元

现有的 Agent 大多是一次性、任务驱动的工具：缺乏上下文、孤立运行，需要在不同窗口和模型之间手动交接；即使有记忆，也往往全局、浅层而缺乏个性。LobeHub 改变这一切——它是一个工作与生活空间，用于发现、构建并与会随你一起成长的 Agent 队友协作。在 LobeHub 中，Agent 被视为工作单元，人类与 Agent 在同一套基础设施上共同进化。

## 运营：你制定策略，它运行 Agent

雇用、排程并汇报你整个 AI 团队的工作。更高生产力，更少工具：所有 Agent 集中在一个平台；IM 网关让 Agent 进入你已经在用的聊天工具，长程任务派发下去，睡觉时也在推进。

## 创建：一句话组建 AI 团队

构建个性化 AI 团队从 Agent Builder 开始：只需描述一次需求，名称、角色、技能与行为自动配置完成，即刻可用。统一智能无缝接入任何模型与任何模态，全部由你掌控；一万多个工具与 MCP 兼容插件组成的技能生态，把 Agent 连接到你每天使用的工具。

## 协作：扩展新型协作网络

Agent Groups 让你像对待真实队友一样与 Agent 协同：系统为任务组装合适的 Agent，并行协作、迭代改进。页面（Pages）让多个 Agent 共享上下文、在同一处撰写与润色内容；日程（Schedule）让 Agent 在你离开时按时执行；项目（Project）与工作区（Workspace）把团队工作组织得结构化、权责清晰。

## 进化：人类与 Agent 的共生进化

个人记忆（Personal Memory）构建对你的清晰理解；持续学习让 Agent 从你的工作方式中学习，调整行为以在恰当时刻行动；白盒记忆结构化、可编辑，Agent 记住什么完全由你掌控。

LobeHub 在 GitHub 开源，提供 Docker 镜像与自托管版本，可以把整套服务部署在自己的设备上。
