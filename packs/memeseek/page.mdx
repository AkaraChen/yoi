MemeSeek 是面向个人使用的梗图管理工具：把梗图集中保存起来，用多模态 AI 自动识别标题、描述、标签和图片文字，需要时按关键词搜回来。

## 功能

- 梗图上传：点击选择、拖拽上传，或在上传区域按 Ctrl+V 直接粘贴；带预览、真实上传进度和失败提示。
- AI 自动识别：上传后由 OpenAI 兼容视觉模型分析图片，生成标题、描述、标签和 OCR 文字；分析中、完成、失败三种状态可见，失败可重新分析。
- 梗图搜索：按标题、描述、标签或 OCR 文字检索，关键词同步到 URL 的 `?q=` 参数。
- 梗图管理：详情查看、标题 / 描述 / 标签编辑、删除（连同本地图片一起删）。
- 两套 AI 配置：分析 AI 与内容 AI 分开设置，API Key 只保存在当前浏览器的 localStorage。

## 前后端闭环

前端是 React + TypeScript + Vite，后端是 NestJS + Prisma + PostgreSQL，收在一个 pnpm workspace 单仓库里。图片经 multipart 上传落到本地磁盘并通过静态资源访问，分析结果进数据库；Swagger/OpenAPI 自动生成接口文档和前端的类型化 Client。

## 两套 AI，各管各的

分析 AI 负责图片理解、OCR、标题、描述和标签，上传和重新分析只走它；内容 AI 为文本改写、自然语言搜索等后续能力预留。每套配置都是 OpenAI 兼容接口地址 + API Key + 模型名，可以从任何兼容服务商接入。

## 定位与边界

官方把 MemeSeek 定位为个人本地工具：没有登录体系，API Key 的浏览器本地存储方案只适合自用，公开部署前还需要补上后端密钥管理与访问控制。作者也把它作为工程能力展示项目——从前端交互到后端存储、数据库与 AI 服务的完整闭环。
